# 📚 AuraTerra - Documentación del Proyecto

Repositorio centralizado de documentación general, diagramas de arquitectura, manuales y especificaciones técnicas de la plataforma agrometeorológica **AuraTerra**.

---

## 📂 Estructura del Repositorio

* **`/arquitectura`**: Diagramas de clases, Entidad-Relación (DER) de Base de Datos y patrones de diseño (MVC, Repository Pattern).
* **`/api`**: Especificaciones de endpoints REST, colecciones de Postman y respuestas JSON.
* **`/manuales`**: Guías de instalación local, configuración de variables de entorno (`.env`) y despliegue.
* **`/minutas`**: Registro de requerimientos, entregables y correcciones del equipo.
